# 동국 식당

캠퍼스 건물 선택과 식당 현황을 연결하는 반응형 화면입니다.
상록원·기숙사 식당(남산학사)·경영관 세 곳을 표시합니다.
세 식당 모두 공식 주간 메뉴를 표시합니다. 상록원 1·2·3층은 더미 혼잡도·발권량도 함께 제공하고,
기숙사·경영관의 혼잡도는 준비 중 상태로 표시합니다.
단독 파일은 저장된 공식 메뉴로 동작하고, FastAPI로 열면 공식 사이트의 변경을 주기적으로 확인합니다.

## 실행

### 팀원 확인용 Vercel 배포

Vercel 정적 화면과 `/api/menus` Python 함수를 지원합니다.
설정과 갱신 방식은 `docs/VERCEL_DEPLOY.md`를 참고하세요.
Vercel에서는 요청 시 메뉴 캐시를 확인하며, 로컬 서버의 상시 갱신 루프와 SQLite 저장 기능은 배포하지 않습니다.

### 자동 메뉴 갱신을 사용하는 실행 (권장)

프로젝트 루트에서 기존 가상환경으로 실행합니다.

```powershell
venv/Scripts/python -m uvicorn main:app --app-dir server --host 127.0.0.1 --port 8000
```

브라우저에서 `http://127.0.0.1:8000/dashboard/`를 엽니다. 종료는 `Ctrl+C`입니다.
필요한 패키지가 없는 환경은 `venv/Scripts/python -m pip install -r server/requirements.txt`로 설치합니다.

### 저장된 메뉴만 사용하는 실행

`web/index.html`을 브라우저로 열면 마지막으로 저장한 공식 메뉴를 볼 수 있습니다.
별도 서버 없이 메뉴 캐시를 갱신하려면 `venv/Scripts/python tools/update_menus.py`를 실행합니다.
단순 HTTP 서버로도 볼 수 있습니다.

```powershell
python -m http.server 5500 --bind 127.0.0.1 --directory web
```

브라우저에서 `http://127.0.0.1:5500`을 엽니다. 종료는 `Ctrl+C`입니다.

## 화면과 동작

- 기본 선택은 상록원 2층 학생식당입니다.
- 입체 캠퍼스에서 건물이나 식당 목록을 누르면 해당 시설로 전환됩니다.
- 입체/평면 보기, 좌우 회전, 초기 시점 복원 버튼이 있습니다.
- 미연동 식당은 점유율과 대기시간을 `—`로 표시합니다. 가짜 혼잡도를 넣지 않습니다.
- 층 요약 카드와 상세 화면의 층 버튼으로 층을 전환합니다.
- 구역 선택 시 점유율, 혼잡 등급, 데이터 상태가 바뀝니다.
- 1층에서는 식음료 매장별 더미 주문 대기시간도 표시합니다.
- 상록원 전체의 최근 5분 키오스크 발권량과 직전 5분 대비 증감 건수·비율을 보여줍니다.
- 더미 데이터는 10초마다 갱신됩니다. 일시정지와 수동 새로고침이 가능합니다.
- 최근 1시간 그래프는 5분 슬롯 13개를 표시하고, 같은 슬롯 갱신은 마지막 값을 교체합니다.
- PC는 구역도와 상세 정보가 좌우에, 모바일은 위아래에 배치됩니다.
- 모든 시간 표시는 `Asia/Seoul` 기준입니다.
- 제목은 고운바탕, 본문은 고운돋움, 큰 수치는 DM Serif Display를 사용합니다. 웹용 글꼴과 라이선스는 프로젝트 안에 포함되어 있습니다.
- 메뉴판 형태의 층 요약, 영수증 형태의 구역 상세, 가상의 입체 식당 공간을 제공합니다.
- 일러스트 부유·기울기, 움직이는 띠, 캐릭터·김 효과, 회전 보간, 숫자 전환, 스크롤 등장과 버튼 반응을 제공합니다.
- 상단 `움직임` 버튼으로 장식 애니메이션을 정지할 수 있습니다. 브라우저의 `prefers-reduced-motion` 설정도 반영합니다.

## 공식 주간 메뉴

- [상록원 / 생활협동조합](https://dgucoop.dongguk.edu:44649/store/store.php?w=4&l=2): 날짜·층·코너별 HTML 표를 읽어 메뉴, 원산지 문구, 게시된 가격·시간을 표시합니다.
- [기숙사 / 남산학사](https://dorm.dongguk.edu/article/food/list): 날짜가 맞는 주간 게시글의 원본 이미지와 PDF 링크를 표시합니다.
- [경영관 / D-Flex](https://www.dongguk.edu/article/FOODDFLEX/list): 날짜가 맞는 주간 게시글의 원본 이미지와 PDF 링크를 표시합니다.

기숙사와 경영관의 이미지 내용을 OCR로 임의 변환하지 않습니다. 원본 이미지를 누르면 큰 크기로 열 수 있습니다.
공식 메뉴와 혼잡도·발권량 더미는 별개이며, 메뉴를 구역 점유율이나 대기시간으로 환산하지 않습니다.

서버 실행 중에는 캐시 만료를 매분 확인하고, 세 사이트를 한 시간 간격으로 수집합니다.
서버 화면은 5분마다 API를 조회합니다. `새로 확인`으로 수동 갱신할 수도 있습니다(공식 사이트 요청 최소 간격 1분).
오늘을 포함한 게시글을 우선 선택하고, 없으면 가장 최근 적용 기간의 게시글을 선택합니다.
적용 기간이 지난 자료와 예정 자료는 각각 **지난 식단 / 예정 식단**으로 표시합니다.
원문 수집 실패 시 마지막 성공 자료와 **저장된 식단** 안내를 유지하며, 데이터가 전혀 없으면 공식 링크를 제공합니다.
상록원 표의 공란을 휴무로 해석하지 않습니다. 범위가 다른 캠퍼스의 메뉴도 포함하지 않습니다.

`web/menus.json`, `web/menu-cache.js`, `web/assets/menus/`는 수집 결과입니다.
단독 실행 시 자동 수집되지 않으므로 표시된 공식 자료 확인 시각을 확인해야 합니다.

## 데이터의 의미

시설 이름은 [동국대학교 공식 안내](https://www.dongguk.edu/page/202)와 [남산학사 공식 홈페이지](https://dorm.dongguk.edu/main)를 참고했습니다.
캠퍼스는 건물의 위치·크기·외형을 임의로 구성한 개념도입니다. 실제 지도, 동선, 길찾기에 사용할 수 없습니다.
3D 공간 좌표를 SVG 화면에 투영하는 가벼운 입체 표현이며, 실제 건물 모델이나 WebGL 엔진은 사용하지 않습니다.
층별 내부 배치와 출입구는 예시이며, 실제 평면도가 아닙니다. 테이블 모양은 장식이며 좌석 수나 개별 좌석 상태를 의미하지 않습니다.
구역 점유율, 시간별 이력, 대기시간은 시연용입니다. 운영시간·좌석 수·3층 이용 대상은 확인되지 않아 표시하지 않습니다.
층 점유율은 시연용 구역 점유율의 단순 평균입니다. 실제 연동 시 구역별 좌석 수를 반영한 집계가 필요합니다.
1층은 매장별 대기시간 범위를, 2·3층은 임시 배식 대기시간을 표시합니다. 현재 대기시간 공식은 검증된 예측 모델이 아닙니다.

혼잡 등급: 여유 ≤30%, 보통 30% 초과·70% 미만, 혼잡 ≥70%.
편의점·문구점·기획사는 시설 안내에만 포함하고 식사 공간 점유율에서는 제외합니다.

### 키오스크 발권량

발권량은 건수이며 현재 대기 인원과 다를 수 있습니다. 주문 흐름을 보는 보조 지표로 제공하고,
대기 인원·좌석 점유율·대기시간으로 직접 환산하지 않습니다.
현재 범위는 **상록원 전체**로, 층이나 구역을 선택해도 발권량의 범위는 바뀌지 않습니다.

- 최근 5분: `[기준 시각 - 5분, 기준 시각)`
- 직전 5분: `[기준 시각 - 10분, 기준 시각 - 5분)`
- 첫 시연값: 최근 42건, 직전 24건 → +18건(+75%)
- 기준은 마지막 갱신 시각입니다. 자동 갱신을 끄면 기준 시각과 발권량도 함께 멈춥니다.
- 새 발권 더미는 경과한 시간에 맞춰 생성하며, 새로고침 클릭 횟수로 발권이 늘지 않습니다.
- 직전 발권량이 0건이면 증감률 대신 증감 건수만 표시합니다.
- 데이터 미연동·오류는 `—`/데이터 없음으로, 정상 수신된 0건과 구분합니다.

실제 연결 시 `timestamp`와 해당 시점의 신규 발권 `count`를 전달해야 합니다.
누적 발권 카운터나 매번 중복되는 5분 합계를 그대로 합산하면 안 됩니다.
더미 모드의 일시정지 후 이력 보충은 시연용이며, 실제 수신 누락을 보충하는 로직이 아닙니다.

## 파일과 다음 연동

- `index.html`: 화면 구조와 접근성 레이블
- `shared.js`: DOM 선택, 날짜 포맷, HTML 이스케이프와 클릭 위임
- `styles.css`: PC·태블릿·모바일 레이아웃
- `data.js`: 건물별 시설·표시 상태, 개념도 좌표, 층별 더미 데이터
- `campus.js`: 입체 건물 투영, 회전·평면 전환, 선택 버튼 배치
- `room.js`: 가상의 입체 식당, 가구·캐릭터와 구역 선택
- `kiosk.js`: 최근·직전 5분 발권 집계와 시간 기반 더미 생성
- `menus.js`: 공식 메뉴 표시, 날짜·층 선택, API 갱신과 오래된 자료 표시
- `menu-cache.js` / `menus.json`: 단독 실행을 위한 공식 메뉴 캐시
- `app.js`: 더미 데이터, 구역·층 선택, 갱신과 그래프
- `assets/`: 자체 생성 식당 일러스트, 웹 글꼴과 라이선스
- `DESIGN_NOTES.md`: 디자인 레퍼런스와 일러스트 생성 프롬프트

새 식당은 `CAMPUS_LOCATIONS` 항목으로 추가합니다. `mode: "pending"`은 시설 안내만,
`mode: "demo"`와 `floors`는 더미 층·구역 화면을 활성화합니다. 실제 센서 연동 상태는 별도 API로 확장해야 합니다.

## 검증 범위

```powershell
venv/Scripts/python -m unittest discover -s tests -v
node tests/frontend_smoke.cjs
```

자바스크립트 구문과 모의 DOM에서 건물·층·구역 선택, 준비 중 상태, 자동 갱신과 입체 투영 계산을 확인합니다.
실제 브라우저 연결이 없는 환경에서는 CSS 배치·렌더링 검증을 수행할 수 없습니다.

글꼴은 현재 HTML·JS·CSS에 포함된 문자로 Google Fonts에서 서브셋을 내려받았습니다.
새 텍스트를 추가할 때 해당 문자가 없으면 폴백 글꼴이 표시되므로 글꼴 서브셋도 갱신해야 합니다.
프로젝트 루트에서 `powershell -NoProfile -File tools/update_web_fonts.ps1`로 갱신할 수 있습니다(네트워크 필요).

`server/menu_service.py`에서 공식 메뉴를 수집·저장하며, `server/main.py`에 `/menus` API와 `/dashboard/` 정적 화면을 추가했습니다.
기존 센서 수신·혼잡도 API는 유지했습니다. `/congestion`은 전체 결과만 제공하므로 혼잡도 화면에는 아직 연결하지 않았습니다.
다음 단계에서는 층·구역 식별자, 갱신 시각, 결측/지연 상태와 점유율 이력을 제공하는 API를 준비하고 `app.js`의 더미 데이터 공급 부분을 교체합니다.
센서 미수신 시 점유율 0%로 대체하지 않고 별도의 데이터 없음 상태로 처리해야 합니다.
