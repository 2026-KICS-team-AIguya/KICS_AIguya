# 동국식당

상록원·남산학사 기숙사 식당·D-plex의 메뉴와 혼잡도를 보여주는 반응형 화면이다.

- 상록원 1층: 실제 CSI 한 쌍의 측정과 AI 결과를 연결한다. 수집 장소는 테스트 공간이며 화면에서는 개발용 테스트 문구를 사용하지 않는다.
- 상록원 2·3층: 예시 혼잡 등급·이력. `예시 데이터`로 구분한다.
- 키오스크: 상록원 1층의 가상 발권·배식 도우미. 1층 선택 시에만 제공하고 2·3층은 준비 중이다. 수량·재고 막대·품절 전망은 표시하지 않는다.
- 기숙사·D-plex: 공식 메뉴·시설 안내, 혼잡도는 준비 중.

좌석별·구역별 점유율은 표시하지 않는다. 키오스크 대기시간은 가상 데이터에 기반한 시연용 추정이다. AI 신뢰도는 모델의 예측 확률이다.

## 실행

프로젝트 루트에서:

```powershell
.\venv\Scripts\python.exe -m uvicorn server.main:app --host 0.0.0.0 --port 8000 --workers 1
```

브라우저에서 <http://127.0.0.1:8000/dashboard/>를 연다. CSI 연결·모델 준비·키오스크 API 규격은 [연결 문서](../docs/CSI_INTEGRATION.md)를 참고한다.

희수 컴퓨터에서 수집기를, 송주 컴퓨터에서 백엔드를 실행한다. 같은 공유기의 다른 컴퓨터는 `http://송주컴퓨터IP:8000/dashboard/`로 접속한다. 웹과 API가 같은 주소를 사용하므로 별도 프론트 서버나 API 주소 설정이 필요 없다.

`web/index.html` 또는 단순 정적 서버로 열면 저장된 메뉴와 2·3층 예시 데이터를 확인할 수 있다. 별도 혼잡도 주소가 없으면 1층은 혼잡도 준비 중 상태다.

Vercel은 메뉴 API와 정적 화면을 배포한다. 별도 백엔드가 준비되면 빌드 환경변수 `CONGESTION_API_BASE`에 HTTPS 주소를 넣는다. 메뉴 API 주소 `DINING_API_BASE`와 혼잡도 주소는 별개다.

## 화면

기본 선택은 상록원 1층이다. 캠퍼스 건물·층 선택, 입체/평면 보기, 회전과 장식 애니메이션을 지원한다. 가상의 식당 내부 그림은 장식이며 실제 좌석 상태나 건물 배치가 아니다.

혼잡도는 10초마다 조회하고, 자동 갱신 정지·수동 갱신을 지원한다. 준비 중, 확인 중, 업데이트 지연, 연결 오류를 구분한다. 실제 입력은 `실시간 혼잡도`, 인공 입력은 `예시 데이터`, 파일 재생은 `기록 데이터`로 표시한다. 최근 한 시간 그래프는 정상 추론의 5분 요약 등급을 표시한다. 누락된 구간의 이력을 임의로 채우지 않는다.

키오스크는 `랜덤`과 `실측 기반` 버튼으로 전환한다. 실측 기반은 정상 수신 중인 1층 CSI 혼잡도에 맞춰 브라우저에서 가상 발권을 구성하며 센서가 없으면 수신 대기로 표시한다. 두 모드 모두 인원·발권량은 목데이터다. 인원은 최대 120명이고 10초 연속 갱신의 인원·최근 5분 발권량 변화는 각각 최대 1이다. 코너 카드는 표시하지 않는다. 실제 CSI 등급과 출처를 구분한다. 상세 API·계산 원칙·배포 연결은 [키오스크 문서](../docs/KIOSK_SERVICE.md)를 참고한다. 기존 실제 발권 수신 및 고정 시연 API는 호환용으로 유지한다.

시간 표시는 `Asia/Seoul`이다. 고운바탕·고운돋움과 DM Serif Display를 사용하며 글꼴 라이선스가 `assets/fonts/`에 있다. 움직임 버튼과 `prefers-reduced-motion`을 지원한다.

## 메뉴

주간 식단은 기본적으로 접힌 토글이다. 제목을 누르거나 키보드 Enter/Space로 펼치며, 자동 갱신 중에도 펼침 상태를 유지한다.

- 상록원: 생활협동조합의 날짜·층·코너별 HTML 식단표.
- 기숙사·D-plex: 학교가 게시한 주간 식단표 원본 이미지·PDF.

공식 메뉴는 센서 결과와 독립적으로 갱신한다. 수집 실패 시 마지막 성공 자료와 안내를 유지한다. 적용 기간이 지난 자료와 예정 자료는 별도로 표시하고, 공란을 휴무로 해석하지 않는다.

`menus.json`, `menu-cache.js`, `assets/menus/`는 수집 결과다. 단독 파일은 자동 수집하지 않는다. 메뉴 캐시 수집은 서버에서 매분 만료를 확인하고 한 시간 간격으로 수행하며, 화면은 5분마다 조회한다.

## 코드

- `shared.js`: 날짜 포맷·HTML 이스케이프·클릭 처리.
- `data.js`: 시설 정보와 2·3층 더미 등급.
- `congestion.js`: 혼잡도 API 조회·상태 처리.
- `app.js`: 층별 화면·시연 이력·캠퍼스 상호작용.
- `kiosk.js`: 가상 키오스크 조회·시연 제어·분석 카드 표시.
- `room.js`, `campus.js`: 장식용 입체 SVG.
- `menus.js`: 공식 식단 표시.

## 검증

프로젝트 루트에서 `node tests/frontend_smoke.cjs`와 `python -m unittest discover -s tests -v`를 실행한다. 프론트 검사는 mock DOM으로 AI 상태, 더미 층, 발권량, 연결 오류, 갱신·화면 선택을 확인한다. 실제 브라우저 배치와 센서 현장 검증은 별도다.
