# 코드 정리 기록 — 2026-10-08

화면 디자인과 계산 결과를 유지하면서 읽기 어려운 부분을 정리했습니다.

- `web/shared.js`: 날짜 포맷, HTML 이스케이프, DOM 조회와 클릭 위임 공통 처리
- `web/menus.js`: 헤더, 날짜별 메뉴, 이미지 메뉴 렌더링을 분리
- `web/app.js`: 반복 클릭 처리와 안내 문구를 합치고 초기화 순서를 명시
- `server/menu_service.py`: 캐시 갱신 판단, 수집, 실패 처리와 저장을 분리
- `server/predict.py`: 사용하지 않는 구역 매핑을 제거하고 변수·주석을 정리
- `web/index.html`, `web/styles.css`: 구조가 보이도록 정렬하고 불필요한 공백을 정리

프론트엔드의 14개 시나리오는 정리 전 출력과 비교했습니다. 서버 테스트 7개와
혼잡도 계산의 전후 비교도 통과했습니다. CSS의 선택자·선언·순서와 HTML 구조·텍스트는 동일합니다.
브라우저의 실제 렌더링을 확인한 결과는 아닙니다.

로컬 정적 빌드까지 확인했습니다. Git 커밋·push와 Vercel 재배포는 하지 않았습니다.
현재 배포 사이트에는 이 정리가 반영되어 있지 않습니다.
